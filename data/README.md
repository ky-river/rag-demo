# Demo Documents

This directory contains two synthetic documents for local demos and
evaluation:

- `rag_project_document.pdf`
- `AI实习生_个人简历_测试.pdf`

They contain fictional resume data and can be committed to the repository.
Do not commit a real resume or confidential company documents. Other PDF
files in this directory are ignored by Git.

Uploading a PDF through the web interface rebuilds the Chroma and BM25 indexes
from every PDF currently in this directory.
